xui est un SDK de pages server-rendues pour plugins xcore — jamais un prérequis, jamais une couche kernel. Cette documentation est elle-même servie par un plugin xui (docs_site), et chaque exemple de composant ci-après est un vrai <ui.x> rendu en direct, pas une capture d'écran.

Principes fondateurs

  • Le serveur est la seule source de vérité pour la sécurité.
  • Un seul système d'auth, deux façades (API pure et pages xui).
  • Compatible par construction avec tout frontend externe — un plugin React/Vue n'importe jamais xui.
  • Chaque appel réseau est explicite, tracé — aucun dispatcher générique.
