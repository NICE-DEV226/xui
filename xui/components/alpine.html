{# Point de montage Alpine pour une page XUI — à poser une fois en fin de (typiquement dans le layout de base ou sur les pages interactives). Charge Alpine core + les plugins nécessaires aux composants (collapse → accordion, focus → x-trap des dialog/drawer) depuis les assets auto-hébergés du SDK (`/xui-static/alpine/`), dans le bon ordre `defer`. Le plugin `x-teleport` (drawer/dialog/tooltip) est intégré au core Alpine >= 3.13 : inutile de le charger séparément. Pour les pages SANS interactivité, ne pas inclure ce composant (pas d'Alpine chargé). #}
